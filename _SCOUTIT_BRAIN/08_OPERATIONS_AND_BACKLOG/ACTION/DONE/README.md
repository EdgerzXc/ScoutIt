# Done — monthly evidence index

Completed tasks leave live queues immediately. Each closure receives one concise
row in the current month containing the task, close date, evidence, and any
remaining boundary. Detailed walkthroughs belong in
[[15_IMPLEMENTATION_RECORDS/README|Implementation Records]], not here.

## Files

- [[08_OPERATIONS_AND_BACKLOG/ACTION/DONE/2026-08|August 2026]]

## Rules

1. Never copy the full task description into Done.
2. Never keep a checked copy in Urgent, Active, Waiting, or Owner.
3. Evidence must be behavior, a verified test/build, a commit/deployment, or a
   connected live-system read—not merely a created file.
4. One month per file. Start a new file when the month changes.
