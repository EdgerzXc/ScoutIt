**This is the only router. There is no other starting point.**

> **SUPERSEDED 2026-08-22. Use [[08_OPERATIONS_AND_BACKLOG/00_START_HERE|Operations Start Here]].**

This folder holds **work**: what is left to do, what only the owner can do, what
is deliberately deferred, and the rules any change must obey. It does **not**
hold the record of what exists — that lives elsewhere, on purpose.

## What was wrong before this reorganisation (2026-08-13)

Recorded so the same drift is recognisable if it returns:

1. **Three files each claimed to be the starting point** — the root `README.md`
   pointed at `BACKLOG/`, `BACKLOG/00_START_HERE.md` pointed at `01_WORK_ORDER`,
   and `ACTION/00_START_HERE.md` declared the master plan the only live list.
   Each was written by a consolidation that never removed the previous one.
2. **`ACTION/00_START_HERE.md` said ~40 files had "moved to `_ARCHIVE/`". There
   was no `_ARCHIVE/` folder.** All 70+ were still sitting in the root. The
   consolidation was described but never performed — which is why the folder
   became unreadable.
3. **Two competing to-do lists.** `BACKLOG/01_WORK_ORDER.md` (W1–W30) and the
   master action plan. A diff found **real work in the work order that the master
   plan never had** — it has now been merged in, not discarded.
4. **The work order had duplicate IDs** — two different W23s and two different
   W24s — so "do W23" was ambiguous.

**The rule that prevents a repeat:** *one item, one home.* If something appears
in two files, one of them will go stale and the stale one will be believed.
