# Brand source

`SIT Assets.png` is the original SIT monogram board the ScoutIt logo was traced
from (2026-09-12). It is the **source of truth for the mark's shape** and the
only copy — it is not generated by anything, and nothing regenerates it.

## What derives from it

```
Assets/SIT Assets.png                  the render (this folder)
  └─ src/components/brand/markPath.js  traced vector: 2 contours, fill-rule evenodd
       ├─ src/app/icon.svg             favicon / PWA / app icon
       ├─ src/components/brand/ScoutItMark.js       the mark in the UI
       ├─ src/components/brand/ScoutItImageMark.js  OG + Twitter cards
       └─ scripts/build-icons.mjs      every raster: favicon.ico, apple-icon,
                                       public/icons/*, mission-control/*
```

`build-icons.mjs` reads `markPath.js`, **not this PNG** — so the repo builds
without it. It is kept because losing it means losing the ability to re-trace
or revisit the original artwork.

## How it was traced

Not with an auto-tracer. A glossy 3D render produces hundreds of junk nodes
from its own highlights. Instead:

1. **Threshold on chroma (`R - B > 70`), not brightness.** The gold's shaded
   bevel is dark but still gold; a luminance threshold punched holes straight
   through the ring, and a lower one swallowed the glow halo.
2. **Crop stops at row 486** — below that is the render's reflection, separated
   from the mark by a 2-row gap that a blur will happily weld shut.
3. **Morphological close (r=3)** heals the seam the specular highlight cuts
   through the top bar.
4. Marching-squares contours → smoothing → Douglas-Peucker.

If the mark is ever redrawn, put the new source here and update `markPath.js`,
then re-run `node scripts/build-icons.mjs`.

## Known limit

The full mark stops being legible below about 32px — the tapered points and the
thin ring close up. A simplified micro mark for the 16px favicon is still
outstanding.
